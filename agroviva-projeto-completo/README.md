# AGROVIVA — Campo Vivo

Vitrine institucional cinematográfica + console operacional para monitoramento e manejo de canteiros de olericultura.

## Como rodar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Para gerar a build de produção:
   ```bash
   npm run build
   ```
